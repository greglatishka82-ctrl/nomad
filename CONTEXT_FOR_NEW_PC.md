## ПРОЕКТ
Автошкола NOMAD — система онлайн-записи на уроки вождения.

## СТРУКТУРА ПРОЕКТА
```
NOMAD/
├── backend/          # FastAPI бэкенд (Telegram бот + AI чат + API)
├── admin/backend/    # Админ-панель (FastAPI)
├── admin/frontend/   # Фронтенд админки (HTML/CSS/JS)
├── frontend/         # Лендинг сайт (HTML/CSS/JS)
├── whatsapp-bot/     # WhatsApp бот (Node.js + Baileys)
├── instructor_bot/   # Бот для инструкторов (Telegram)
└── .env              # Переменные окружения
```

## ПЛАН: ПЕРЕЕЗД НА VPS (DigitalOcean)

### Почему переезжаем с Render:
- Render перезапускает контейнеры — WhatsApp сессия теряется
- Всё в одном месте дешевле
- Прямой контроль через SSH

### Выбранный тариф DigitalOcean:
- **Droplet**: Basic, Regular SSD
- **План**: $6/mo — 1 vCPU, 1 GB RAM, 25 GB SSD, 1000 GB Transfer
- **OS**: Ubuntu 24.04 (LTS) x64
- **Регион**: NYC1
- **Авторизация**: Password (проще)

### Что нужно сделать на новом ПК:
1. Создать Droplet на DigitalOcean (сайт уже открыт)
2. Получить IP адрес сервера
3. Сказать мне IP — я создам .bat файл для деплоя
4. Настроим сервер (установка зависимостей, pm2, nginx)
5. Зальём проект на VPS
6. Настроим автозапуск всех сервисов
7. Перенесём домены с Render/Vercel на VPS

### Схема деплоя (без GitHub):
- Правки делаем локально
- .bat файл копирует изменения напрямую ПК → VPS через scp/rsync
- pm2 restart all на сервере

## ВАЖНЫЕ ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Переменные окружения (.env):
- BOT_TOKEN — Telegram бот токен
- DATABASE_URL — PostgreSQL на Render (пока)
- OPENAI_API_KEY — для AI чата
- ADMIN_SECRET — для админки

### Технологии:
- Backend: Python, FastAPI, SQLAlchemy, aiogram, asyncpg
- Frontend: HTML, CSS, JavaScript (чистый, без фреймворков)
- WhatsApp: Node.js, Baileys
- БД: PostgreSQL
- Деплой: pm2 (планируется), nginx (планируется)

### Инструкторы:
- Список инструкторов хранится в БД (не в коде)
- Считывается динамически из базы данных
- Управляется через админ-панель
