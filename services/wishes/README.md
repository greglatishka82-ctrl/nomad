# Пожелания посетителей

Снимок работающего сервиса и ресурсов интерфейса. Сервис запускается в отдельном контейнере, подключённом к сети приложения; маршруты сайта `/api/wishes` и админки `/api/admin/wishes*` направляются в него через шлюз. Для проверки сессии требуется доступ к `admin-api`.

Сервису необходим секрет `WISHES_HASH_KEY` в окружении и постоянный отдельный том, подключённый к `/data`. Файлы окружения и база с обращениями не включены в репозиторий. `Dockerfile.site` и `Dockerfile.admin` описывают слои поверх текущих образов интерфейсов VPS.
