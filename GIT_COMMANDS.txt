  ПОЛНОЕ ОБНОВЛЕНИЕ GITHUB (ТОЧНАЯ КОПИЯ)
================================================

Скопируй эти команды по порядку в Git Bash:

cd /d/work/Жека/NOMAD

git add -A

git commit -m "Полное обновление: светлая минималистичная тема"

git push origin main --force

================================================

ЕСЛИ ОШИБКА, ПОПРОБУЙ ЭТО:

cd /d/work/Жека/NOMAD

git add -A

git commit -m "Полное обновление: светлая минималистичная тема"

git push origin master --force

================================================

ЧТО ДЕЛАЮТ КОМАНДЫ:

1. cd /d/work/Жека/NOMAD
   → Переходит в папку проекта

2. git add -A
   → Добавляет ВСЕ изменения (новые, измененные, удаленные)

3. git commit -m "..."
   → Создает коммит с описанием

4. git push origin main --force
   → ПОЛНОСТЬЮ перезаписывает GitHub твоей локальной версией
   → --force означает принудительное обновление
