# KRANOFF — сантехническая служба в Павлодаре

Проект по ТЗ v4.0 (с учётом уточнений заказчика): сайт, админ-панель, клиентский Telegram-бот, бот мастера, рабочая страница мастера с геолокацией.

## Что уже работает

- Публичный сайт RU/KZ/EN: услуги и цены, аварийный вызов, гарантия, зона обслуживания, контакты, политика конфиденциальности, кнопки в Telegram/WhatsApp/телефон.
- Клиентский бот `@kranof_bot`: выбор услуги, заявка, 3 фото + 1 видео, срочность, «Мои заказы», поддержка, контакты, RU/KZ/EN.
- Админ-панель: главная, заказы, карта, клиенты, мастера, услуги и цены, поддержка, аналитика, смены и админы, журнал действий, настройки.
- Удаление заказа в любой момент с подтверждением (из карточки или списка), вместе с медиа и историей; запись об удалении сохраняется в журнале.
- Журнал действий: все действия администраторов понятным русским языком, только чтение, без очистки; по 50 строк на страницу, снизу переходы по страницам от первой до последней.
- Бот мастера `@kranmaster_bot`: привязка по телефону, «На линии / Занят / Завершить смену», предложения с принятием за 5 минут, «Выехал / На месте / Начал / Выполнено», заработок за смену и 24 часа, история.
- Рабочая страница мастера `/m/<token>`: карта, точный синий маршрут до адреса (OSRM), расстояние и время в пути, сворачиваемая нижняя панель, кнопки этапов, передача геопозиции каждые 5 секунд.
- Карта админа: 4 статуса мастеров (свободен / в пути / на объекте / занят вручную), легенда над картой, мастера без смены скрыты. Назначение через карту: заказ сверху, ближайший подходящий мастер пульсирует, клик по мастеру — мини-карточка с навыками и кнопкой «Предложить».
- Медиа: до 3 фото + 1 видео в заявке, 2 фото «после» от мастера, удаление медиа пачкой, ZIP-архив по выбранным заказам или за неделю (карточка PDF + фото + info.txt).
- PDF-карточка заказа с кириллицей.
- Расчёт: мастер получает 70% от стоимости работ, материалы не входят; ночной тариф ×2 для обычных работ; аварийные вызовы — отдельный тариф.

## Временные адреса

Пока домена нет, всё работает через временный HTTPS-туннель Cloudflare:

- Сайт: https://adaptation-ever-gibraltar-namely.trycloudflare.com
- Админка: https://adaptation-ever-gibraltar-namely.trycloudflare.com/admin
- API здоровья: https://adaptation-ever-gibraltar-namely.trycloudflare.com/api/health
- Страница мастера: ссылка вида `/m/<token>` — берётся в карточке мастера или в боте мастера.

> Туннель временный. Если контейнер `kranoff-tunnel` перезапустить, адрес изменится. Для продакшена нужен домен (например, `kranoff.kz`) и HTTPS.

## Доступ в админку

- Логин: `admin`
- Пароль: задаётся в `ADMIN_PASSWORD` в `.env` (реальный пароль в репозиторий не коммитится).

Смените пароль: **Настройки → Пароль администратора** (после смены все сессии завершатся).

## Первые шаги

1. **Настройки** — заполните телефон и часы работы, проверьте имя Telegram-бота. Сейчас телефон пустой, поэтому кнопка звонка на сайте скрыта, работает Telegram. Тексты сайта, адрес, гарантия и районы управляются разработчиком, не из админки.
2. **Услуги и цены** — проверьте 52 стартовые позиции и цены (они ориентировочные, «от»). Цены меняются прямо в таблице; услуги можно добавлять и удалять, категории — добавлять.
3. **Мастера** — добавьте мастеров: имя, телефон, навыки, инструменты, районы, ночные выезды. Мастер открывает `@kranmaster_bot`, нажимает `/start` и отправляет свой номер — бот привяжется к карточке.
4. **Смена** — администратор нажимает «Начать смену» в панели. Мастер отмечается «На линии» в боте.
5. Проверьте заказ из бота: заявка появится в админке со звуком, далее подтверждение → назначение → выезд → прибытие → выполнение → проверка → закрытие.

## Как устроен заказ

1. Клиент выбирает услугу в боте, указывает имя, телефон, проблему, фото/видео, желаемое время и срочность. Адрес в боте не спрашивается — его уточняет администратор.
2. Заявка приходит в админку. Администратор смотрит медиа, звонит клиенту, уточняет адрес, домофон, кто встречает.
3. Администратор назначает мастера через карту: «Назначить» → заказ сверху. Если у заказа нет точки, кликните по карте — точка сохранится, и ближайший подходящий мастер запульсирует. Клик по мастеру → мини-карточка с навыками → «Предложить». Мастер получает сначала фото клиента, затем карточку заказа.
4. Если мастер молчит 5 минут — администратор звонит; можно переназначить. У старого мастера предложение аннулируется.
5. Мастер принимает, указывает время прибытия, нажимает «Выехал», затем «На месте», «Начал работу», «Выполнено».
6. Администратор связывается с клиентом, проверяет качество и уборку, вносит сумму, гарантию и материалы, закрывает заказ.
7. Мастер видит заработок за заказ, за смену и за последние 24 часа; в истории — все заказы.

## Деньги

- Мастер получает **70% от стоимости работ** (без материалов). Настраивается в «Настройки → Доля мастера».
- Материалы: клиент покупает сам, мастер покупает с чеком (клиент компенсирует), либо служба. В системе материалы — комментарий, без отдельного учёта (по требованию заказчика).
- Ночной тариф: с 22:00 до 08:00 по Павлодару, ×2 для обычных работ. Аварийные вызовы тарифицируются отдельно (дневной/ночной).
- Онлайн-оплаты, кассы и взаиморасчётов в системе нет — по ТЗ этот контур отдельно.

## Сервер и изоляция

- Проект развёрнут в `/home/ubuntu/kranoff` на VPS `57.129.153.111`.
- Контейнеры: `kranoff-app` (Node.js), `kranoff-tunnel` (Cloudflare Quick Tunnel).
- Сеть: `kranoff_net`. Порт приложения — только `127.0.0.1:8787` на хосте.
- Существующий проект и Caddy (GREENTIME) **не тронуты**: порты 80/443 не используются, общих сетей и томов нет.
- Логи ограничены 10 МБ × 3 файла.

Команды:

```bash
cd /home/ubuntu/kranoff
docker compose ps
docker compose logs -f app
docker compose up -d --build app
docker compose restart app
```

Обновление после правок: скопировать `server/` и/или `web/`, затем `docker compose up -d --build app`.

## Если туннель перезапустился

```bash
cd /home/ubuntu/kranoff
URL=$(docker logs kranoff-tunnel 2>&1 | grep -Eo 'https://[a-zA-Z0-9.-]+\.trycloudflare\.com' | tail -1)
sed -i "s|^PUBLIC_BASE_URL=.*|PUBLIC_BASE_URL=$URL|" .env
docker compose up -d app
echo $URL
```

Либо запустить `./refresh-url.sh`.

## Ограничения текущей версии

- Нет домена: временный адрес Cloudflare, меняется при перезапуске туннеля.
- Нет интеграции с WhatsApp API и телефонией: WhatsApp и звонки — вручную, как в ТЗ.
- Нет SMS: клиенты без Telegram получают информацию от администратора по телефону/WhatsApp.
- Акт и договор с гарантией — бумажные бланки компании; система формирует карточку заказа PDF и архив, но не заменяет бумажный акт.
- Нет онлайн-оплаты и финансовой сверки.
- Нет отзывов/рейтингов и старших специалистов (по уточнению заказчика).
- Токены ботов и пароли — в `.env` на сервере (права 600). Не публикуйте их.

## Боты

- Клиентский: `@kranof_bot`
- Мастерский: `@kranmaster_bot`
- Работают через long polling, вебхук не нужен — поэтому временный адрес не влияет на приём сообщений.
- Мастер привязывается по номеру телефона: `/start` → «Отправить номер».
- Клиент может писать в поддержку; ответ приходит в тот же чат. WhatsApp ведётся отдельно администратором.
