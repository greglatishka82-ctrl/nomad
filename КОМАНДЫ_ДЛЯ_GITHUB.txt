================================================
  КОМАНДЫ ДЛЯ ПОЛНОГО ОБНОВЛЕНИЯ ПРОЕКТА НА GITHUB
================================================

Скопируй и вставь эти команды по порядку в Git Bash:

# 1. Добавить все изменения
git add .

# 2. Создать коммит с описанием
git commit -m "Обновлен дизайн: применена светлая минималистичная тема"

# 3. Отправить изменения на GitHub (полное обновление)
git push origin main --force

================================================

Если будет ошибка с main, попробуй:
git push origin master --force

================================================

АЛЬТЕРНАТИВНЫЙ ВАРИАНТ (без force):

git add .
git commit -m "Обновлен дизайн: применена светлая минималистичная тема"
git pull origin main --rebase
git push origin main

================================================
